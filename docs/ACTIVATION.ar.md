# دليل التفعيل بالعربي (مختصر، للموبايل)

الحالة في 25 نوفمبر 2026. النموذج في كل الاختبارات تجريبي (MOCK) ولا يوجد نموذج حي. الـ12 مشروع **مش كلهم شغالين**.

## شغال ومختبر
- خط الإنتاج: LangGraph، فحص المسودة، بوابة الموافقة بالهاش (أي تعديل بعد الموافقة بيتمنع).
- Repomix وCrawl4AI وRemotion: اتجربوا محليًا، وRemotion وn8n وMetabase اتجربوا كمان على جهاز AWS مؤقت اتحذف بعد التجربة (نتائج محدودة، بيانات اختبار فقط، السجلات ما اتحفظتش).
- مراجعة النص العربي: فحوصات اللغة وصفحة مراجعة RTL وكرت عربي. **لازم إنسان يقرأ العربي قبل أي نشر.**

## مش شغال بعد
- نموذج حي: المسارات المجانية اتخنقت، ومفتاح xAI بدون رصيد ومش مستخدم.
- Postiz وTryPost وLangfuse وComfyUI: ما اتشغلوش أبدًا. محتاجين سيرفر، وPostiz وTryPost محتاجين تطبيقات مطوّر LinkedIn وX بحساباتك.
- مقاييس حقيقية: مفيش، ولا بنخترع أرقام.

## القرارات اللي عليك
1. مسار النموذج (رصيد مدفوع أو مسار تاني).
2. ترخيص المشروع، وأي رفع على GitHub (مفيش رفع قبل موافقتك على نسخة معينة).
3. لو عايز تجربة AWS تانية لتشغيل Postiz/TryPost/Langfuse: موافقة جديدة، مش تلقائي.

## قواعد ثابتة
- مفيش نشر تلقائي. كل نص بتوافق عليه بنفسه في واتساب.
- المفاتيح بتتحط في رابط الخزنة فقط، مش في الشات، وبتتحذف بعد الاستخدام.
- التفاصيل الكاملة بالإنجليزي: ACTIVATION.md وCOVERAGE.md وINTEGRATION_EVIDENCE.md.
